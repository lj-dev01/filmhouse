# User Stories

## Regular Users

As a user, I want to view available movies so that I can decide what I want to watch.

As a user, I want to create an account so that I can access the movie booking system.

As a registered user, I want to log in so that I can view and manage my bookings.

As a user, I want to view showtimes for a movie so that I can choose a suitable screening.

As a user, I want to create a booking by selecting a showtime and number of tickets so that I can reserve cinema tickets.

As a user, I want the system to check seat availability so that I cannot book more tickets than are available.

As a user, I want to receive confirmation messages after actions so that I know whether my booking was successful or unsuccessful.

As a user, I want to see clear error messages when I enter invalid information so that I know how to correct it.

## Admin Users

As an admin, I want to add new movies so that users can see films currently available.

As an admin, I want to update movie details so that information remains accurate.

As an admin, I want to delete movies so that unavailable films can be removed from the system.

As an admin, I want to create showtimes so that users can book tickets for scheduled screenings.

As an admin, I want to delete showtimes so that cancelled screenings are removed from the system.

As an admin, I want to view all bookings so that I can manage cinema reservations.

As an admin, I want to view registered users so that I can monitor system accounts.
