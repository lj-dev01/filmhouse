## Problems / Blockers

- Encountered Node.js version compatibility issues when setting up the Vite frontend environment
- Encountered SQLite database locking issues while DB Browser was open during backend write operations, needed to “write changes”
- Browser default validation popups conflicted with the custom FILMHOUSE frontend design
- Navbar did not immediately update after login because the component was not rerendering after token storage

## Decisions Made

- Decided to use Vite for frontend setup instead of Create React App
- Decided to use Axios for API communication between frontend and backend
- Chose to disable browser default form validation and replace it with custom React validation
- Decided to store JWT authentication tokens in browser local storage
- Decided to implement separate protected route components for authenticated users and admin users
- Decided that the FILMHOUSE logo should function as the homepage navigation link instead of using a separate Home button
- Decided that admin users should not see the “My Bookings” link and instead manage bookings through the admin dashboard
- Chose a dark cinematic UI theme with gold accent colours to reinforce the cinema branding
